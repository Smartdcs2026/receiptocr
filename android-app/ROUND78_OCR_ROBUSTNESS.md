# Round78 OCR robustness

- สะสมผล OCR จากภาพบิลหลายช่องตามหมายเลข POS
- ไม่ทับข้อมูลเดิมที่อ่านดีหรือข้อมูลที่ผู้ใช้กรอกเองแบบเงียบ ๆ
- ภาพใหม่สามารถเติม POS ที่ยังขาดและซ่อมช่อง OCR เดิมที่มีคำเตือน
- เพิ่ม local contrast, glare-safe pass, adaptive threshold, stroke repair และ narrow overlapping crops
- แยกข้อความที่อยู่ห่างกันมากในแนวนอนเพื่อลดข้อมูลคนละบิลไหลมารวมแถว
- ปรับหน้า Admin รูปแบบบิลให้เป็นขั้นตอนและคงหน้าเดิมหลังบันทึก
